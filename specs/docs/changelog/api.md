# API Changelog

> Stay up to date with the latest changes introduced in our API

Polar uses date-based API versions to evolve the API without unexpectedly changing
the contract your integration depends on. Versions use the `YYYY-MM` format, such
as `2026-10`, and apply to API requests, responses, webhook payloads, and SDK types. [Read more](/docs/api-reference/current/versioning)
